# AI Product Buzz Feed

AI Product Buzz Feed is a web app for discovering AI product launches and tech news. It ranks products by buzz using votes, comments, and news mentions.

## Features

- AI product feed
- Buzz score ranking
- Source filtering
- Supabase login
- User profile
- Likes and like history
- Save items into Drawers
- Feedback form
- Modern dark purple UI

## Tech Stack

- Next.js
- TypeScript
- React
- Supabase
- Tailwind CSS
- Framer Motion
- Vitest
